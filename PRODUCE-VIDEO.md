# 🎬 GUIDE DE PRODUCTION VIDÉO E-SELLER

## Options pour Créer la Vidéo

---

## OPTION 1 : Utiliser un Outil TTS (Texte-à-Voix)

### ElevenLabs (Recommandé)

1. **Aller sur** : https://elevenlabs.io
2. **Créer un compte** gratuit
3. **Aller dans** Voice Library
4. **Chercher une voix française** :
   - Masculine : "Damien", "Alain", "Thomas"
   - Féminine : "Léa", "Julie", "Camille"
5. **Copier le script** depuis VIDEO-SCRIPT.md
6. **Générer l'audio**
7. **Télécharger** en MP3

### Azure AI Speech (Gratuit)

1. **Aller sur** : https://speech.microsoft.com
2. **Créer une ressource** Speech
3. **Utiliser l'API** avec les voix :
   - Masculine : "fr-FR-HenriNeural"
   - Féminine : "fr-FR-DeniseNeural"

### Google Cloud Text-to-Speech

1. **Aller sur** : https://cloud.google.com/text-to-speech
2. **Voix françaises** :
   - Masculine : "fr-FR-Standard-A"
   - Féminine : "fr-FR-Standard-B"

---

## OPTION 2 : Utiliser un Générateur Vidéo IA

### HeyGen (IA Avatar)

1. **Aller sur** : https://heygen.com
2. **Créer un compte**
3. **Choisir un avatar** français
4. **Coller le script**
5. **Générer la vidéo**

### Synthesia

1. **Aller sur** : https://synthesia.io
2. **Choisir un avatar**
3. **Coller le script**
4. **Télécharger la vidéo**

### Runway ML

1. **Aller sur** : https://runwayml.com
2. **Utiliser Gen-2** pour les scènes
3. **Combiner avec audio TTS**

---

## OPTION 3 : Studio Professionnel

### Étapes pour un Studio Local

1. **Enregistrer la voix** :
   - Microphone USB (Blue Yeti, Rode NT-USB)
   - Logiciel : Audacity (gratuit)
   - Logiciel : Adobe Audition

2. **Créer les visuels** :
   - Canva (canva.com)
   - PowerPoint + export vidéo
   - Figma + plugin vidéo

3. **Assembler** :
   - CapCut (gratuit)
   - DaVinci Resolve (gratuit)
   - Adobe Premiere (payant)

## 📤 EXPORT ET DIFFUSION

### Formats Recommandés

| Plateforme | Résolution | Format | Durée max |

| TikTok | 1080x1920 | MP4 | 60 sec |

### Configuration Export
- **Codec** : H.264
- **Bitrate** : 8-12 Mbps
- **Audio** : AAC 256kbps
- **FPS** : 30 fps
